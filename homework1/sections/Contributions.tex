\begin{description}
	\item[Alessandro Perin] Architected and implemented the core Data Logic Layer, including the PostgreSQL database schema (\texttt{init.sql}) with advanced functionalities such as UUIDs, ENUMs, JSONB, and defensive DDL constraints. Developed the fundamental DAO layer (\texttt{WalletDAO}, \texttt{TransactionDAO}, \texttt{RecurringExpenseDAO}) and the comprehensive REST API backend for the Recurring Expenses feature. This included building the Service logic with strict ownership validation, custom exception handling, and an extensive suite of integration tests. Finally, drafted the LaTeX documentation relative to the Data Logic Layer and the Entity-Relationship structures.
	\item[Rajmonda Bardhi] Designed and implemented the Dashboard Aggregation Service. Built the \texttt{DashboardDAO} with optimized SQL queries to compute per-wallet balances and aggregate statistics (total equity, year-to-date expenses, and year-to-date savings) grouped by currency. Developed the \texttt{DashboardService} to handle data retrieval and create the \texttt{DashboardSummary} response object. Created the \texttt{DashboardServlet} handling authenticated GET requests, and the corresponding JSP view. Defined the model classes \texttt{DashboardStats}, \texttt{DashboardSummary}, and \texttt{WalletSummary}. Added additional query methods to \texttt{TransactionDAO} and wrote unit and integration tests for the dashboard layer. Finally, wrote the Objectives section of the LaTeX documentation, describing the system goals and the rationale behind each feature.
