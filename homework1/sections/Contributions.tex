\section{Group Members Contribution}

% For each group member, describe in detail the contribution to the project.

\begin{description}
	\item[Alessandro Perin] Architected and implemented the core Data Logic Layer, including the PostgreSQL database schema (\texttt{init.sql}) with advanced functionalities such as UUIDs, ENUMs, JSONB, and defensive DDL constraints. Developed the fundamental DAO layer (\texttt{WalletDAO}, \texttt{TransactionDAO}, \texttt{RecurringExpenseDAO}) and the comprehensive REST API backend for the Recurring Expenses feature. This included building the Service logic with strict ownership validation, custom exception handling, and an extensive suite of integration tests. Finally, drafted the LaTeX documentation relative to the Data Logic Layer and the Entity-Relationship structures.
	\item[Rajmonda Bardhi] Designed and implemented the Dashboard Aggregation Service. Built the \texttt{DashboardDAO} with optimized SQL queries to compute per-wallet balances and aggregate statistics (total equity, year-to-date expenses, and year-to-date savings) grouped by currency. Developed the \texttt{DashboardService} to handle data retrieval and create the \texttt{DashboardSummary} response object. Created the \texttt{DashboardServlet} handling authenticated GET requests, and the corresponding JSP view. Defined the model classes \texttt{DashboardStats}, \texttt{DashboardSummary}, and \texttt{WalletSummary}. Added additional query methods to \texttt{TransactionDAO} and wrote unit and integration tests for the dashboard layer. Finally, wrote the Objectives section of the LaTeX documentation, describing the system goals and the rationale behind each feature.
	\item[Meviola Karriqi] Collaborated with the team on the initial project design on the Miro board, which included the first draft of the database schema (later refined by the team). Wrote the Trello tickets and helped divide the work across team members throughout the project. On the implementation side, developed the Wallets feature (Servlet/JSP with PRG), the Transactions REST/JSON API, and the PAC plans feature. Added \texttt{java.util.logging} across the servlets and the \texttt{AuthenticationFilter} to trace errors and security-relevant events. Wrote the Main Functionalities, REST API Summary, REST API Details, and REST Error Codes sections of this LaTeX documentation.
	\item[Danil Smirnov] Designed and implemented the user authentication flow, with particular focus on the registration and login functionalities. Developed the server-side logic for account creation and credential validation through components such as \texttt{LoginServlet}, \texttt{RegisterServlet}, \texttt{UserService}, and \texttt{UserDAO}, and connected the login and registration pages to the backend workflow. Defined the initial domain model classes used across the application, including \texttt{User}, \texttt{Wallet}, and \texttt{Transaction}. Also contributed to the initial setup of page access control filters, such as \texttt{AuthenticationFilter} and \texttt{GuestSessionFilter}, to separate protected pages from guest-only pages. For the report, also prepared the sequence diagram and the Presentation Logic Layer section.
	\item[Giacomo Masiero] Designed and implemented the complete guest calculator feature. Developed \texttt{CalculatorService} with three financial calculators (loan amortization,compound interest, and budget analysis) and the corresponding result model classes(\texttt{AmortizationRow}, \texttt{CompoundResult}, \texttt{BudgetResult}). Implemented the three calculator servlets (\texttt{ReportLoanServlet}, \texttt{ReportCompoundServlet},\texttt{ReportBudgetServlet}) and built \texttt{PdfReportService} using Apache PDFBox to generate downloadable PDF reports for both guest and authenticated users. Created all JSP views in the \texttt{calculator} folder and produced the Class Diagram of the Business Logic Layer section of the documentation.



\end{description}
